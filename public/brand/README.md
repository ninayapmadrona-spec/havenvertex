# Brand assets

Drop the official Haven Vertex logo here as `logo.png` (transparent background,
at least 256×256px). The `LogoMark` component (`src/components/ui/Logo.tsx`)
automatically picks it up across the site — no code changes needed.

Until the file exists, the site falls back to a lightweight placeholder wing
glyph so pages never render a broken image. The placeholder is scaffolding
only, not a redesign of the brand mark — replace it with the real, unaltered
logo file.
