# Welcome banner handshake photo

Drop the real handshake photo here as:

```
public/hero/handshake.jpg
```

Use a `.jpg` — this is a photographic image (cutout or full scene), and JPEG
keeps the file size reasonable for a hero-banner asset loaded on every visit.
If the file you have is a `.png` (e.g. a transparent cutout), that's fine
too — just save it as `public/hero/handshake.png` instead and mention it so
the code path can be updated to match.
