# Background imagery

Drop full-bleed background photos/renders here (e.g. the purple showroom
scene used for the coverflow concept). Recommended:

```
public/backgrounds/showroom.jpg
```

Use a `.jpg` (not `.png`) for photographic images like this — much smaller
file size for the same visual quality, which matters since this renders as
a full-viewport background on every visit. Aim for something in the
1920–2560px-wide range; anything larger just slows the page down without
being visibly sharper as a background.
